QUESTIONS

THE SHORT ANSWERS.

WHICH LANGUAGES ARE SUPPORTED?

English through Whisper and Hindi-English (Hinglish) through Sarvam AI. Cloud deployments on Render use Sarvam for both modes.

HOW LONG CAN A RECORDING BE?

Audio is chunked and summarised map-reduce style, so length is not capped by model context. The app accepts uploads up to 500 MB.

HOW DOES THE CHAT WORK?

Each recording gets its own Chroma index. A question retrieves the top four matching transcript passages, and Mistral answers only from that context.

ARE MY RESULTS SAVED?

Jobs are held in memory for v2.0, so restarting the server clears them. Durable storage is planned for v2.1.

WHAT DO I NEED TO RUN IT?

Python 3.12 and ffmpeg, plus a Mistral API key for summaries and chat. Sarvam is needed for Hinglish and for cloud transcription.
